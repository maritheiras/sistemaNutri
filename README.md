# 🥗 Sistema Nutri

**Sistema de gerenciamento de nutrientes do consumo de refeições**, desenvolvido como estudo de caso no meu Trabalho de Conclusão de Curso (TCC), explorando a ferramenta FlutterFlow.

---

## 📱 Sobre o Projeto

O **Sistema Nutri** é uma aplicação **multiplataforma** (web + mobile) que permite que **nutricionistas** e **pacientes**:

- Cadastrem alimentos e refeições
- Visualizem o histórico de consumo
- Organizem refeições por dia
- Acompanhem o plano alimentar de forma clara e interativa

Tudo isso em uma **interface moderna, intuitiva e responsiva**.

---

## 🛠️ Tecnologias Utilizadas

| Ferramenta     | Função                                   |
|----------------|-------------------------------------------|
| [FlutterFlow](https://flutterflow.io) | Desenvolvimento da UI e lógica do app |
| Firebase       | Autenticação, banco de dados (Cloud Firestore) |
| Flutter        | Build do projeto para Android, iOS e Web |

---

## 🎓 Contexto Acadêmico

Este projeto foi desenvolvido como parte do TCC no curso de **Sistemas de Informação** no Instituto Federal Fluminense (IFF), com o tema:

> **"Sistema de gerenciamento de nutrientes do consumo de refeições: um estudo exploratório da ferramenta FlutterFlow"**

O principal objetivo foi realizar um estudo exploratório sobre a ferramenta **FlutterFlow**, avaliando suas capacidades de criação de sistemas complexos com baixa codificação.
